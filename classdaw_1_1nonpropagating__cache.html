Detailed Description

template<typename T>
class daw::nonpropagating_cache< T >

A cache that is never copied or moved. Copying or moving it gives an empty cache, moving also empties the source, and assigning to it empties it. A view can then cache something like begin( ) that would be invalid in a copy of the view. Filling it requires a non-const cache, as filling a const one would not be safe when used from several threads.

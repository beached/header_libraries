Detailed Description

template<typename CV, ForwardRange... Ranges>
struct daw::pipelines::pimpl::concat_iterator< CV, Ranges >

Iterates the ranges passed to concat_view in sequence. Holds a pointer back to the view, which owns the storage for every range; the iterator only tracks its own current position within that storage so that copies (e.g. via operator++( int )) advance independently.

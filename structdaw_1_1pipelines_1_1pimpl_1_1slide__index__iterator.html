Detailed Description

template<typename First, typename Last = First>
struct daw::pipelines::pimpl::slide_index_iterator< First, Last >

A random access source with a sized end knows how many windows there are up front, so the iterator only needs the window start, how many windows are left and the window length. There is no per step comparison against the end of the source, which lets the compiler see a counted loop.
